# 1v1 — Version 0.3
Prototype RPG au tour par tour. Ouvre `index.html` dans un navigateur.

## Nouveautés
- Arène en perspective avec sprites pixel-art pseudo-3D dessinés en formes facettées.
- Trois ennemis sélectionnables : Griffebraise, Grand Jagras et Rathian (interprétations graphiques originales).
- Six actions : coup rapide, frappe chargée, frappe élémentaire, garde, concentration et potion.
- Énergie, bonus de faiblesse au feu contre le Grand Jagras, bonus de concentration, animations et barres de PV.

## GitHub Pages
Dans ton dépôt `1v1`, remplace le fichier `index.html` par celui-ci. Puis Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save.
Les sprites sont originaux et ne copient pas les ressources officielles de Monster Hunter ou Pokémon.
